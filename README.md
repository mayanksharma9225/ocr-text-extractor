# 🧾 OCR Text Extractor

## 📌 Description
This project extracts text from images using OCR (Optical Character Recognition) with OpenCV and Tesseract.

## 🚀 Features
- Extract text from images  
- Simple command-line interface  
- Uses OpenCV preprocessing  

## 🛠️ Tech Stack
- Python  
- OpenCV  
- Tesseract OCR  

## ▶️ How to Run

1. Install dependencies  
pip install -r requirements.txt  

2. Install Tesseract OCR  
https://github.com/tesseract-ocr/tesseract  

3. Run the program  
python main.py
